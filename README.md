# Дипломная работа: Автотесты для Кинопоиска

Проект реализует автоматизацию тестирования веб-интерфейса и API сервиса Кинопоиск. Покрытие включает позитивные и негативные сценарии (поиск, навигация, валидация структуры).

## Стек технологий

- Python 3.10+
- pytest — фреймворк для запуска тестов
- Playwright — UI-тесты (браузерное тестирование)
- requests — API-тесты
- Allure — формирование отчётов
- flake8 — контроль качества кода

## Структура проекта

```
diplom-project/
├── api/                # API-тесты и вспомогательные модули
├── ui/                 # Page Objects и UI-тесты (Playwright)
├── tests/              # Общие фикстуры, утилиты, конфиги
├── allure-results/     # Отчёты Allure (создаётся автоматически)
├── requirements.txt    # Зависимости
└── README.md           # Текущий файл
```

## Установка и запуск

### Установка зависимостей

```bash
pip install -r requirements.txt
playwright install chromium
```

> Для формирования отчётов Allure требуется установленная Java (версия 8+).

### Запуск всех тестов

```bash
py -m pytest
```

### Запуск с генерацией отчёта Allure

```bash
py -m pytest --alluredir=allure-results
allure serve allure-results
```

### Запуск только UI-тестов

```bash
py -m pytest ui/tests -m ui
```

### Проверка качества кода

```bash
python -m flake8 api ui
```

## Результаты автоматизации

- **Общее количество тестов:** 18 (API + UI)
- **Статус:** 17 passed, 1 expected failure
- **Expected failure:** негативный тест API-08 зафиксировал известный дефект внешнего API (PATCH /v1.4/movie возвращает 200 вместо 405), баг-репорт заведён в TestIT, статус «Открыт»
- **Отчётность:** Allure-отчёт с детализацией по шагам, длительности и браузеру (Chromium)

## Примеры сценариев

- **UI-тесты:** открытие главной страницы, проверка блока карточек фильмов, поиск по существующему и несуществующему запросу, переход в раздел сериалов.
- **API-тесты:** валидация кодов ответов, проверка структуры JSON-ответов, соответствие полей документации.
